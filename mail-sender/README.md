# 학생 안내 메일 발송 (Google Apps Script)

담임이 **신청서를 승인/반려**하거나 **결과보고서를 승인/반려**하면, 학생이 가입할 때 쓴 이메일로 결과를 자동으로 안내합니다.
메일은 이 스크립트를 배포한 구글 계정의 Gmail로 나갑니다. (개인 Gmail은 하루 약 100통까지)

## 동작 방식

1. 담임이 사이트에서 승인/반려를 누르면 사이트가 이 스크립트 주소로 요청을 보냅니다. (로그인 토큰 포함)
2. 스크립트는 토큰을 확인하고, **그 사람의 토큰으로 Firestore를 직접 읽어** 승인된 담임인지, 본인 반 학생의 신청서인지 확인합니다. (Firestore 보안 규칙이 그대로 적용됩니다.)
3. 받는 사람은 신청서에 저장된 학생 이메일, 내용은 DB에 저장된 승인/반려 결과와 담임 메모입니다. 요청으로 임의의 주소나 문구를 보낼 수는 없습니다.
4. 처리한 지 5분이 지난 요청이나 이미 보낸 건은 다시 보내지 않습니다.

## 배포 순서 (한 번만)

1. 메일을 보낼 구글 계정(개인 Gmail)으로 로그인한 뒤 [script.google.com](https://script.google.com)에서 **새 프로젝트**를 만듭니다.
2. 기본으로 있는 `Code.gs` 내용을 지우고, 이 폴더의 `Code.gs` 내용 전체를 붙여넣고 저장합니다.
3. 위쪽 함수 선택에서 **`authorize`**를 고르고 **실행**합니다. 권한 요청 창이 뜨면 계정을 고르고 **고급 > (안전하지 않음) 이동 > 허용**합니다. (메일 보내기와 외부 요청 권한입니다.)
4. 오른쪽 위 **배포 > 새 배포**를 누르고, 유형에서 톱니바퀴를 눌러 **웹 앱**을 고릅니다.
   - 설명: `field-trip mail`
   - 다음 사용자 인증으로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. **배포**를 누르면 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.
6. 사이트 폴더의 `firebase-config.js`에서 `mailEndpoint`에 그 주소를 넣고 GitHub에 올립니다.

```js
export const mailEndpoint = "https://script.google.com/macros/s/여기에주소/exec";
```

## 코드를 고친 뒤

`Code.gs`를 수정하면 **배포 > 배포 관리 > 연필 아이콘 > 새 버전**으로 다시 배포해야 반영됩니다. (웹 앱 URL은 그대로입니다.)

## 알아 두실 점

- 하루 발송 한도를 넘으면 메일이 가지 않고 화면에 "안내 메일을 보내지 못했습니다"가 나옵니다. 승인/반려 자체는 정상 처리됩니다.
- 학생이 가입할 때 입력한 이메일은 본인 확인을 하지 않습니다. 오타가 있으면 다른 사람에게 갈 수 있습니다.
- 스팸함으로 들어갈 수 있으니 학생들에게 안내해 주세요.
- 이 스크립트는 `Code.gs` 위쪽의 `PROJECT_ID`, `API_KEY`, `SITE_URL`을 쓰며, 사이트 주소나 Firebase 프로젝트를 바꾸면 같이 바꿔야 합니다.
